# Simple Task Manager App

A simple task manager application that demonstrates writing and reading from files. Users can log in, register, and manage tasks effectively.

## Features

- **User Registration**: Admin can register new users with a secure password policy.
- **Task Management**: Users can add tasks, view all tasks, and check their specific tasks.
- **Statistics**: Admin can view total users and tasks.
- **File Storage**: User data and tasks are stored in text files.
